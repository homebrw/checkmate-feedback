# Politique de sécurité

Merci de **ne pas signaler publiquement** une vulnérabilité, un secret exposé ou un problème susceptible d'affecter la confidentialité des utilisateurs.

N'ajoutez jamais dans une issue publique :

- clé API, jeton, mot de passe ou autre secret ;
- URL privée ou identifiant d'infrastructure sensible ;
- donnée personnelle ou donnée concernant un enfant ;
- preuve photo, capture d'écran non anonymisée ou contenu familial privé.

Pour un signalement de sécurité, utilisez les canaux privés proposés par GitHub lorsque ceux-ci sont disponibles sur ce dépôt. Si aucun canal privé n'est proposé, n'ouvrez pas d'issue publique.

Les issues publiques contenant accidentellement des informations sensibles peuvent être masquées ou supprimées.
